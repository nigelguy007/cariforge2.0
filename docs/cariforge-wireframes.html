Forge Canvas builder

Node-based blueprint editor (Kore.ai-style): drag agents from the palette, wire the flow on the canvas, tune the selected node in the inspector. Save is versioned and immutable; Validate runs the semantic graph checks; Safe test executes the deterministic simulator.
